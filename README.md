## 🚀 Featured Projects

### 🔹 AXI Interconnect Design & Verification

**RTL Design | AMBA AXI | SystemVerilog**

Developing an AXI-based interconnect to understand communication between multiple masters and slaves.

**Key Highlights:**

- AXI write and read transaction flow.
- AW, W, B, AR, and R channels.
- Address decoding for multiple slaves.
- Multiple master and slave communication.
- FIXED, INCR, and WRAP burst types.
- AXI address calculation and write strobes.
- SystemVerilog constraints for valid transactions.
- Verification of interconnect functionality.

### 🔹 APB-Based SPI Master Protocol — Design & Verification

**Verilog | SystemVerilog | UVM | APB | SPI**

Designed and verified an APB-to-SPI bridge for bus-to-peripheral communication.

**Design Features:**

- APB interface and register access.
- SPI master controller.
- Configurable SPI clock generation.
- Serial data transmission and reception.
- MOSI, MISO, SCLK, and Slave Select.
- CPOL and CPHA configuration.
- Shift-register-based data transfer.

**Verification Features:**

- UVM-based verification environment.
- APB and SPI agents.
- Active and passive agent topology.
- Sequencer, driver, and monitor communication.
- Scoreboard-based data checking.
- Functional coverage and assertions.
- Constraint-random verification.

📌 **Repository:** Coming Soon
